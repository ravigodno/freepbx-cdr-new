# Changelog

## 5.6.43 - 2026-07-29

### Improved

- Таблица справочника стала плотнее: строки, телефоны и действия получили стабильную компактную геометрию.
- Ширины колонок перераспределены в пользу должности, а организация теперь адаптируется к длине названия без лишнего пустого пространства.
- Длинные ФИО, организации и должности сокращаются многоточием и раскрываются в доступной всплывающей подсказке.
- Горизонтальная прокрутка на узких экранах локализована внутри контейнера таблицы.

## 5.6.42 - 2026-07-28

### Fixed

- Удалено ограничение чтения последних 1000 строк CDR в реестре звонков и связанной статистике.
- Фильтры периода, номера и статуса теперь применяются ко всем CDR-записям выбранного периода.

## 5.6.41 - 2026-07-28

### Fixed

- Исправлена совместимость миграции заданий импорта справочника с MariaDB, где `row_number` является зарезервированным именем.
- Восстановлен последовательный запуск миграций 062–068, включая создание таблиц раздела «Баланс».
- Исправлен конфликт зарезервированного псевдонима `rows` в DB Explorer.

## 5.6.40 - 2026-07-28

### Added

- Раздел «Баланс» преобразован в центр проверки легитимности списаний оператора.
- Добавлена сводка подтверждённых звонков, операций без соответствия CDR, ожидаемых услуг, спорных списаний и поступлений.
- Детализация разделена на «Звонки», «Другие списания» и «Платежи и баланс».
- Каждая операция получила понятный статус и объяснение результата проверки.

### Improved

- Для звонков отдельно отображаются стороны вызова, направление, длительность, стоимость, использование пакета и результат сверки с CDR.
- Технические типы событий MTS заменены понятными пользовательскими названиями.
- Финансовые таблицы и итоговые карточки используют одинаковую серверную фильтрацию.

### Fixed

- Нулевые операции и события без суммы исключены из списаний и платежей.
- Звонки больше не смешиваются с абонентской платой, услугами и пополнениями.

## 5.6.39 - 2026-07-28

### Added

- Добавлена реальная интеграция MTS Business API: OAuth-токен, текущий баланс, кредитный лимит и безопасные серверные настройки подключения.
- Добавлена машинная детализация MTS по номеру и лицевому счёту с дневным разбиением диапазонов, дедупликацией и хранением истории.
- Добавлена автоматическая загрузка номеров лицевого счёта через `HierarchyStructure` и фильтрация детализации по счёту и номеру.
- Детализация разделена на звонки и финансовые операции; для звонков отображаются стороны, направление, длительность, стоимость и статус сверки с CDR.

### Improved

- Синхронизация детализации защищена от параллельных запусков и сохраняет выбранную вкладку интерфейса.
- Фильтры детализации выстроены в компактную горизонтальную строку.
- История качества связи собирается круглосуточно и хранится для периодов до 30 дней независимо от открытой вкладки.

### Fixed

- Исправлен сбой вкладки детализации при отсутствующих числовых значениях.
- Большие ответы MTS обрабатываются по дневным диапазонам без превышения лимита ответа.
- Исправлено разделение сторон входящих и исходящих звонков для последующей сверки с CDR.

## 5.6.38 - 2026-07-26

### Fixed

- Восстановлено накопление истории доступности Online/Offline и SIP RTT независимо от наличия активных RTCP-сессий.
- Устранена гонка автообновления, из-за которой выбранные периоды 7 и 30 дней могли перезаписываться пустым часовым ответом.

- Реальные jitter, RTP loss и MOS по-прежнему отделены от архивных расчётных значений и отображаются только при наличии RTCP.

### Fixed

- Исправлены частичный поиск телефона, многополевый поиск с произвольным порядком токенов и защита от устаревших ответов запросов.
- Исправлено одновременное отображение загруженной формы контакта и состояния «Контакт не найден».

## 5.5.4 - 2026-07-03

### Added

- Добавлены новые разделы в матрицу прав доступа в панели управления (Permissions Matrix):
  - **Скрипты разговоров** (управление сценариями разговоров операторов).
  - **Умный автоответчик** (настройка AI-автоответчика и LLM интеграций).
  - **AI администратор** (AI-ассистент администратора АТС для диагностики и логов).
- Настроена глобальная видимость модулей: суперпользователь (`su`) может полностью отключать данные модули для всех пользователей. По умолчанию во время разработки эти разделы скрыты от всех пользователей (`false`).
- Расширены настройки AI-провайдеров во вкладке `AIPBXAdmin`: добавлена поддержка Google Gemini, OpenAI, Anthropic и DeepSeek с динамическим выбором моделей и температуры.

### Fixed

- Исправлена ошибка синтаксиса (Unterminated string literal) в файле обработчика диагностики `server/aiPbxAdmin.ts`.
- Успешно протестирована сборка и линтинг всего приложения перед релизом.


## 2.1.1 - 2026-06-11

### Changed

- Default start date (`startDate`) is now initialized to the 1st of the current month instead of 7 days ago (`getDefaultStartDate`).
- Filter reset button ("Сбросить фильтры") now applies the current month preset (`applyThisMonthPreset`) instead of the 7-day preset, completely resetting the dashboard and lists to the beginning of the month.
- Optimized and improved the responsive interface rendering and Russian localization rules.

## 2.0.0 - 2026-06-08

### Added

- 24-hour `from` / `to` time filtering for call lists and dashboard statistics.
- Russian date picker with Monday-first calendar layout.
- HMAC-signed authentication tokens to prevent client-side role tampering.

### Changed

- Bumped application version from `1.0.0` to `2.0.0`.
- Date filtering now uses local date values instead of UTC-derived ISO date strings in the UI.
- Restored normal multi-line source formatting after resolving the GitHub merge conflict.


### Security

- Removed shell-based recording lookup and replaced it with safe in-process path resolution constrained to the recordings root.
