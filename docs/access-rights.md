# Матрица прав и видимость разделов

Каталог `shared/accessCatalog.ts` содержит 176 действующих прав. Названия разделов
используются одновременно в левом меню, матрице и настройках видимости SU.
GSM-шлюзы и телефон представлены отдельно. AI-сотрудники, навыки,
интеграции, телефония, голоса, обучение и базы знаний входят в AI Platform.
AI администратор относится к мониторингу, как в действующем интерфейсе.

Поиск находит права по разделу, названию, описанию и техническому ключу.
Несколько слов уточняют результат. Во время поиска найденные разделы раскрываются.
Галочка «Весь раздел» имеет три состояния: выключено, частично, включено.
Она меняет все доступные для редактирования права раздела, включая скрытые поиском.
Ограничения «только свои» и «только подчинённых отделов» сохраняются; они
настраиваются отдельно. Защищённые права нельзя изменить общей галочкой без
разрешения на их редактирование. Изменения роли сохраняются кнопкой «Сохранить права».
Индивидуальные права пользователя сохраняют прежний приоритет над ролью.

«SU: видимость разделов системы» включает все основные разделы, а также
существующие переключатели подразделов AI. Отключение родительского раздела
скрывает его подразделы. Для старой конфигурации GSM наследует отключённое
«Управление», пока ему не задано отдельное значение. SU сохраняет доступ ко всем
разделам и возможность вернуть настройки. Отключение раздела не стирает права ролей.

Видимость сохраняется в существующей таблице MariaDB `settings`, ключ
`access.module_visibility`. До первого явного сохранения используются прежние
значения; затем SQL имеет приоритет независимо от общего режима настроек.
Ошибка чтения SQL не заменяется разрешающими значениями. При ошибке сохранения
интерфейс возвращает прежнее состояние. Общий API настроек не может обойти
отдельный SU-only API видимости. Миграция всей подсистемы пользователей и ролей
в этой задаче не выполняется.

Телефон открывается из левого меню при наличии `make_calls`, в том числе
при свёрнутом меню. Используются прежние обработчики телефона/гарнитуры,
внутренний номер и настройки устройства. Escape закрывает окно. Реальные звонки
не требуются для проверки интерфейса.

Проверки из корня репозитория с выделенным Node.js:

```bash
node node_modules/tsx/dist/cli.mjs scripts/test-access-catalog.ts
node node_modules/tsx/dist/cli.mjs scripts/test-monitoring-tab-permissions.ts
node node_modules/tsx/dist/cli.mjs scripts/test-quality-permission.ts
PBXPULS_TEST_JSDOM=/путь/к/jsdom node scripts/test-access-ui.mjs
npm run lint
npm run build
```

DOM-тест использует jsdom 26.1.0 и подменяет API/звонки. SQL-тест
`scripts/test-access-visibility-sql.ts` предназначен только для отдельной
`pbxpuls_release_test` через `PBXPULS_TEST_ADMIN_SOCKET`; он восстанавливает
проверяемую настройку. На рабочей АТС его запускать не нужно.

При обновлении матрицы серверный процесс PBXPuls должен быть обновлён вместе с интерфейсом: прежний API поддерживает только часть разделов. Интерфейс проверяет, что ответ сервера содержит все отправленные значения, и показывает ошибку при неприменённом изменении.

Для локальной MariaDB можно задать `PBXPULS_DB_SOCKET_PATH`; тогда runtime и `scripts/pbxpuls-db.ts --check` используют Unix socket с прежними учётными данными. Без этой настройки сохраняется подключение по host/port.

## Несохранённые изменения

При смене вкладки настроек, переходе через боковое меню или выходе из системы появляется диалог «Сохранить / Не сохранять / Остаться». Он учитывает общие настройки, права ролей, карточку пользователя, уведомления, телефонные книги и интеграции сайтов. При ошибке сохранения переход не выполняется. Кнопка «Сохранить настройки» сохраняет изменённые формы, включая привилегии SU. Фоновые загрузки не заменяют изменённые черновики.

Автоматически сохранённые переключатели видимости и настройки интерфейса не считаются черновиками. При закрытии или обновлении страницы браузер показывает своё стандартное предупреждение; сохранить через него нельзя, нужно отменить уход и сохранить на странице. Если сохранение создаёт одноразовый пароль/токен, интерфейс остаётся на странице с полученными данными.

Проверка диалога: `PBXPULS_TEST_JSDOM=/путь/к/jsdom node scripts/test-unsaved-settings.mjs`.
