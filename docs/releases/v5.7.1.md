# PBXPuls v5.7.1

Дата: 03.08.2026

## Исправлено

- `react-is` добавлен как явная runtime-зависимость `recharts`;
- production-сборка больше не зависит от поведения npm при автоматической установке peer dependencies.

- изменение не затрагивает API, настройки или схему базы данных;
- патч предназначен для чистых установок и обновлений на Node.js 18/npm 9.

## Проверено

- установка зависимостей;
- тесты Центра уведомлений;
- тесты SLA пропущенных звонков;
- production-сборка frontend и backend.
