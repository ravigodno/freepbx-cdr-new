# PBXPuls 5.8.4

Released: 2026-08-11

## Added

- Dedicated «Заявки» tab in Reports.
- KPI cards for lead volume, unique applicants, calls, successful contacts and SLA.
- Charts for daily dynamics, processing funnel, statuses, sources, sites and forms.
- Report visibility follows the site-form reports permission and the global site-leads setting.

## Architecture

- MariaDB is documented as the only persistent store for PBXPuls runtime and business data.
- Existing mutable JSON storage is classified as legacy technical debt for incremental migration.

## Verification

- `npm run test:site-form-leads`
- `npm run build`
