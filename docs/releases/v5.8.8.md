# PBXPuls v5.8.8

Дата: 12.08.2026

## Добавлено

- переработанный попап активного звонка с отдельными блоками вызывающего и вызываемого абонента;
- два настраиваемых слота данных справочника с автоматическим заголовком;
- поиск номера через выбранную поисковую систему и возможность временно закрыть попап;
- настройки интерфейса, реестра звонков и попапа активного звонка;
- фильтрация реестра по клику на номер и открытие справочника по клику на распознанное ФИО;
- дополнительные форматы даты, включая `ДД-ММ-ГГ`.

## Исправлено

- распознавание коротких внутренних номеров и показ данных вызывающего абонента;
- загрузка всех видимых пользовательских полей справочника в попап;
- форматирование пользовательских полей типа «Дата» согласно настройкам интерфейса;
- стабильное отображение времени начала и хронометража звонка.

## Хранение DTMF

- создана таблица MariaDB `pbxpuls.dtmf_events`;
- запись и чтение событий `DTMFBegin`/`DTMFEnd` переведены с JSON на MariaDB;
- сохранённые legacy-события импортируются миграцией `20260812_082_dtmf_event_history`;
- добавлены индексы по `Linkedid` и времени события.

## Проверено

- профильные тесты live-call popup и server clock;
- production-сборка frontend и backend;
- миграция DTMF: 30 исходных и 30 импортированных уникальных событий;
- HTTP, PM2 и подключение AMI после применения.
