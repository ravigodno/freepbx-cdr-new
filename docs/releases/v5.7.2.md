# PBXPuls v5.7.2

Дата: 03.08.2026

## Исправлено

- параллельные CDR-ветки одного входящего звонка с ошибочно разными корневыми `linkedid` объединяются в одну строку реестра по строгим дополнительным признакам;
- реестр в legacy-режиме получает ФИО внутренних абонентов из рабочего справочника `data/db.json`;
- короткие внутренние номера сопоставляются с обычными телефонными полями, `internalExtension` и `extension`.

## Улучшено

- уведомление «Нет перезвона по пропущенному в рамках SLA» показывает полный номер звонящего и полный UID/linkedid;
- хеш UID по-прежнему используется для внутренней дедупликации события.

## Безопасность и совместимость

- доступ к частным legacy-контактам учитывает существующие правила видимости;
- fallback объединения CDR ограничен одинаковой секундой создания Asterisk, внешним номером, входящим направлением, пересекающимся временем и сочетанием отвеченной/неотвеченной веток;
- схема базы данных и конфигурация FreePBX не изменяются.

## Проверено

- тесты определения входящего звонка и реестра CDR;
- тесты Центра уведомлений;
- production-сборка frontend и backend на Node.js 18/npm 9;
- запуск и HTTP health-check на `vigodnopbx`.
