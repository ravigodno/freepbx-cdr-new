# PBXPuls v5.8.32

Добавлено штатное включение конференции из поп-апа активного звонка и автоматическое отображение версии в настройках.

## Конференции

ConfBridge может быть установлен, но кнопка конференции недоступна, если служебные контексты PBXPuls не загружены. Новый скрипт использует существующий шаблон setup/pbxpuls_conference.conf.

После обновления приложения выполните на АТС под root:

```bash
cd /opt/asterisk-cdr-panel
bash scripts/enable-conferences.sh --preview
bash scripts/enable-conferences.sh --apply
```

Скрипт сохраняет extensions_custom.conf и шаблон в отдельную закрытую папку /root/pbxpuls-conference-backup-*, добавляет три контекста и выполняет только dialplan reload. Asterisk не перезапускается. Повторный запуск при загруженных контекстах ничего не меняет; при частичной конфигурации скрипт останавливается для ручной проверки. Ошибка загрузки вызывает восстановление исходного файла и повторное чтение dialplan.

Диагностика проверяет все три загруженных контекста, поэтому учитывает и конфигурацию через include. Для создания конференции по-прежнему необходимы настроенный AMI с правами Originate/Redirect и право make_calls у пользователя либо роль admin/su.

## Версия в настройках

Справа от заголовка «Настройки системы» показано PBXPuls v5.8.32. Значение берётся из package.json во время сборки, а не задаётся вручную в интерфейсе. После стандартного обновления со сборкой и перезагрузки страницы метка показывает новую версию.

## Проверки и ограничения

- npm run test:conference-readiness: существующие, отсутствующие, неполные контексты и цветной вывод Asterisk.
- npm run build.
- На рабочей АТС создана резервная копия, загружены все три контекста, проверены повторный запуск без изменений и HTTP 200 приложения.
- Проверка установленного сервиса подтверждает готовность контекстов при настроенном AMI. Реальные вызовы Originate/Redirect и тестовый конференц-звонок не выполнялись.
- Новых зависимостей и миграций базы нет. Для других установок включение dialplan выполняется отдельной явной командой; обновление приложения само его не меняет.
