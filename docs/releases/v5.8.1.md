# PBXPuls v5.8.1

Дата: 11.08.2026

## Исправлено

- заявки с сайта отображаются в общем реестре без предварительного включения отдельного фильтра;
- звонки и заявки объединяются в одну хронологическую ленту с общей пагинацией;
- исправлено сохранение CDR-связи заявки из-за неверного количества значений SQL;
- CDR-сопоставитель использует московское время и своевременно находит новые звонки;
- обработанные вне SLA заявки показываются красным стикером «Обработано»;
- настройка позволяет полностью скрыть блок заявок и его счётчик.

## Интеграция 1С-Битрикс

- одна Pull-интеграция поддерживает несколько реальных сайтов Bitrix;
- сайты и формы обнаруживаются через API, включая конфигурации `s1`, `s2`, `s3` и другие;
- формы группируются по сайтам, выбираются независимо и фильтруются по наличию телефона;
- tracker передаёт идентификатор сайта при кликах по ссылкам `tel:`;
- исправлена проверка нового токена сопряжения при наличии старой статической конфигурации;
- обновлён установочный архив коннектора.

## Проверено

- заявки `vigodno.org`, `grunin.org` и третьего сайта обнаружены одной интеграцией;
- тестовая заявка импортирована и связана с отвеченным CDR-вызовом;
- контрактные тесты заявок с сайта;
- PHP/ZIP-проверки Bitrix-коннектора;
- production-сборка frontend и backend.
