# PBXPuls v5.8.9

Дата: 12.08.2026

## Добавлено

- отдельная вкладка «Кодировка CDR» в Командном центре;
- автоматическая диагностика MariaDB ODBC, драйвера, CDR DSN и UTF-8;
- безопасный workflow «Проверка → Предпросмотр → Исправление»;
- резервная копия `/etc/odbc.ini` перед применением;
- аудит применённых исправлений.

## Безопасность

- пароли ODBC не возвращаются в интерфейс или логи;
- системные пакеты не удаляются и не устанавливаются автоматически;
- FreePBX/Asterisk не перезапускаются автоматически;
- apply доступен только администратору и только для обратимого изменения существующего DSN;
- конфигурация повторно проверяется перед записью.

## Проверено

- тест парсинга и безопасного изменения INI;
- диагностика текущего сервера: `healthy`;
- production-сборка frontend и backend;
- PM2, HTTP и защищённый API мастера.
