# PBXPuls v5.8.0

Дата: 11.08.2026

## Добавлено

- единый рабочий экран заявок с сайта в модуле маркетинга;
- защищённые webhook-интеграции для 1С-Битрикс, Битрикс24 и универсального JSON;
- read-only Pull-коннектор для сайтов 1С-Битрикс за NAT;
- статусы, ответственные, комментарии, планирование звонков и журнал истории;
- автоматическое и ручное связывание заявок со звонками CDR;
- SLA обработки, отчёты, группировки и CSV/XLSX-экспорт;
- отдельные права доступа и события Центра уведомлений;
- отображение заявок и связанных звонков в реестре CDR.
- встроенный мастер подключения сайта для Webhook и 1С-Битрикс Pull API с безопасными примерами настройки.
- отдельный установочный ZIP-модуль для 1С-Битрикс и кнопка скачивания в мастере.
- безопасное сопряжение по одноразовому коду, автоматический выбор `s1/s2`, обнаружение форм и подключение JS-событий кликов по `tel:`.

## Безопасность

- webhook-токены хранятся только как HMAC-хеши и показываются один раз;
- Pull-токены шифруются AES-256-GCM;
- webhook поддерживает HTTPS enforcement, IP allowlist, form allowlist, rate limit и ограничение размера запроса;
- повторный `eventId` обрабатывается идемпотентно;
- массовые операции и удаление интеграций используют Preview → Review → Apply;
- удаление интеграции является мягким: заявки, история и CDR-связи сохраняются.

## Аналитика

- рабочее время компании вынесено в настройки;
- пропущенные входящие вне рабочего времени рассчитываются backend-логикой;
- заявки поддерживают SLA первого звонка и первого успешного контакта.

## Проверено

- контрактные тесты заявок и аналитики;
- миграции `077–080` в отдельной тестовой MariaDB-схеме;
- транзакционное создание заявки и мягкое удаление интеграции с rollback;
- доступность настроенного Bitrix Pull API;
- production-сборка frontend и backend;
- проверка diff и отсутствие секретов в новых файлах.
