# PBXPuls v5.8.16

## Добавлено

- Всплывающий баннер сообщает пользователям с правом `view_site_form_leads` о новых заявках с сайта.
- Из баннера можно открыть заявку, взять её в работу или запустить звонок при наличии соответствующих разрешений.
- Для HTTPS-доступа поддерживаются системные уведомления браузера.

## Надёжность

- Постраничный курсор уведомлений не пропускает заявки при одновременном поступлении большой пачки.
- Очередь баннера защищена от дублей, а заголовок вкладки показывает фактическое число ожидающих заявок.
- Тестовые, дублирующиеся, отклонённые и помеченные как спам заявки не создают баннер.

## Проверено

- `npm run test:site-form-leads` выполняется успешно.
- Production-сборка frontend и backend выполняется успешно.
