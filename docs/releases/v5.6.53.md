# PBXPuls v5.6.53

Дата: 03.08.2026

## Добавлено

- интеграция баланса Новофона через официальный API;
- централизованные настройки подключения, ручное обновление и хранение истории операций;
- отображение источника Новофон в существующем разделе «Баланс».

## Исправлено

- реестр звонков единообразно с таймлайном показывает внутренний номер инициатора исходящего вызова через транк;
- внешний CallerID не скрывается и не подменяет внутреннего абонента;
- click-to-call на чистой установке использует существующий AMI-контекст `from-internal`, если отдельный контекст не задан;
- контакты legacy-справочника снова открываются для редактирования;
- новым ручным контактам автоматически назначается текущий ответственный пользователь;
- запросы Новофона совместимы с официальной схемой подписи и вариантами JSON-ответа.

## Проверено

- исходящие, входящие и внутренние вызовы;
- несколько CDR с общим `linkedid`;
- пустые и строковые нулевые идентификаторы;
- legacy и SQL режимы справочника;
- выбор безопасного контекста click-to-call;
- тесты API Новофона и production-сборка.

## Обновление

```bash
cd /opt/asterisk-cdr-panel
git pull --ff-only origin main
npm run build
pm2 restart asterisk-cdr-panel
```
