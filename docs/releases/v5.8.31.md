# PBXPuls v5.8.31

Исправлены видимость сотрудников в отчётах при ограничении по отделам и удаление дополнительных телефонов контакта.

- Сводки сотрудников и отделов, детализация по внутренним номерам и список сотрудников в фильтре учитывают серверную область доступа. Участие чужого сотрудника в доступном звонке не добавляет его в сводку или список выбора.
- Сервер отклоняет выбор чужого внутреннего номера пустой выборкой отчёта. При включённом ограничении по отделам собственный внутренний номер пользователя добавляется к доступным номерам; это применяется общим механизмом доступа к звонкам, статистике и отчётам.
- Сохранены существующие приоритеты прав: admin/su имеют полный доступ, own_calls_only и роль operator ограничивают выборку собственным номером. Назначение отделов используется при включённом department_calls_only.
- Явно переданный список телефонов контакта заменяет прежний целиком. Удалённый дополнительный номер больше не восстанавливается из phone2. Поддержаны замена основного номера и очистка всех телефонов у контакта с email; запрос без массива phones сохраняет совместимость со скалярными полями.

## Проверки

- npm run build
- npm run test:department-report-access
- npm run test:directory-phone-removal
- npm run test:report-cdr-scope
- npm run test:reports-analytics-enhancements

Ошибка удаления телефона воспроизведена падающим тестом до исправления; после исправления тест проходит.

## Ограничения установки

Новых зависимостей и миграций базы нет. На момент публикации изменения проверены локально; установка и браузерная проверка на боевой АТС не выполнялись. Публикация на GitHub не обновляет работающий экземпляр PBXPuls автоматически. Для применения требуется отдельное обновление приложения и его перезапуск.
