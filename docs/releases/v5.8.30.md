# PBXPuls v5.8.30

Исправлено сопоставление звонков с контактами справочника. Имена сотрудников и клиентов в реестре определяются при первом открытии, без предварительного посещения справочника.

- Сервер запрашивает контакт внутреннего инициатора по `callerExtension` и передаёт его вместе со звонком. Отображение имени больше не зависит от текущей страницы и фильтра справочника.
- Пакетный SQL-поиск учитывает второй телефон, дополнительные телефоны, внутренний и связанный внешний номер. Основной номер имеет приоритет при совпадениях между контактами; совпадение только по части номера не принимается.
- Для больших периодов поиск выполняется пакетами по 500 номеров, без прежнего обрезания после первых 2000.
- Сохранены исправления направлений и значков звонков из v5.8.29.

## Проверки

Production build, TypeScript, регрессии входящих и исходящих звонков и SLA обратного звонка. Отдельно проверены имена при пустом справочнике в браузере, внутренний инициатор, дополнительные номера, приоритет основного номера, отклонение частичных совпадений и наличие условий доступа в SQL-запросах.

На рабочей АТС выполнены чтение данных и проверка сопоставления 12 номеров, включая внутренние 11, 12 и 15. Исправление перед выпуском установлено на этой АТС; приложение запустилось и отвечает HTTP 200.

## Ограничения

Новых зависимостей и миграций базы нет. Контакты и настройки не изменяются. Полный браузерный E2E и нагрузочная проверка дополнительного поиска на многомиллионном справочнике не выполнялись. Поиск по дополнительным номерам может требовать больше времени, чем поиск по индексированному основному номеру. Ограничения установки и AI-пилота предыдущих релизов сохраняются.
