# PBXPuls v5.8.35

- Пропущенные на приветствии назначаются сотрудникам рабочей ветки входящего маршрута, включая ночную ветку с Hangup. Они доступны ответственным в «Моих звонках» с сохранением ограничений доступа.
- SLA перезвона учитывает рабочие интервалы Time Conditions / Time Groups FreePBX, перерывы, выходные, ограничения дат и часовой пояс. Длительность SLA берётся из настроек PBXPuls. Изменения расписания автоматически учитываются при следующем расчёте; часы в коде не фиксируются.
- Для маршрутов без Time Conditions используется общее рабочее время PBXPuls. Исторические звонки пересчитываются по текущей конфигурации.
- При неоднозначном маршруте, неподдерживаемом календаре или активном ручном переключении автоматическая просрочка приостанавливается. История ручных переключений FreePBX не восстанавливается.
- В реестре приветствие и «Ответственный: номер» занимают две строки; номер линии и ФИО в этом блоке убраны. Статусы остаются «Пропущен», «Обработан», «Потерян».

Новых зависимостей и миграций БД нет. Настройки FreePBX не изменяются; для обновления требуется перезапуск только PBXPuls. HTTPS и гарнитура из v5.8.34 сохраняются.

Проверено: сборка, TypeScript, SLA, смена расписания, ночное назначение ответственного, выходные, перерывы, часовые пояса, ограничения доступа. Подробнее: docs/freepbx-callback-sla.md.
