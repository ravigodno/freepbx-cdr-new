# PBXPuls v5.8.2

Дата: 11.08.2026

## Добавлено

- отдельное окно редактирования Pull-интеграции 1С-Битрикс;
- загрузка актуального списка сайтов и форм непосредственно из Bitrix;
- отображение текущего выбора сайтов, форм, телефонного tracker и интервала синхронизации;
- выбор нескольких сайтов и всех форм с телефонными полями;
- сохранение настроек и контрольная синхронизация из окна редактирования.

## Совместимость

- редактор восстанавливает реальные site ID из форм и сохранённых настроек даже со старой версией коннектора;
- обновлённый коннектор дополнительно возвращает названия и домены сайтов;
- повторное сопряжение и замена production-токена не требуются.

## Проверено

- PHP lint Pull API;
- контрактные тесты заявок с сайта;
- production-сборка frontend и backend;
- проверка diff.
