# PBXPuls Desktop Alerts

## Установка для проверки

1. Откройте `chrome://extensions` или `edge://extensions`.
2. Включите режим разработчика.
3. Нажмите «Загрузить распакованное расширение» и выберите каталог `browser-extension`.
4. Откройте расширение, укажите адрес PBXPuls и войдите.
5. Нажмите «Проверить окно звонка» и убедитесь, что Chrome открыл отдельное окно.

Расширение показывает заявки и активные звонки в отдельном окне, перехватывает ссылки `tel:` и позволяет позвонить по номеру, выделенному как обычный текст: выделите номер и выберите в контекстном меню «Позвонить через PBXPuls». В большом окне используются компактные кнопки; для внешнего входящего звонка, включая стадию вызова до ответа, доступна кнопка «В ЧС», которая после подтверждения завершает звонок и добавляет номер в blacklist. Такая же кнопка «В ЧС и завершить» доступна в системном маленьком алерте, пока внешний входящий звонок активен; после завершения звонка кнопка убирается. Большое окно закрывается сразу после завершения звонка; если пользователь закрыл его крестиком раньше, оно не открывается повторно для того же звонка. Маленький алерт звонка, инициированного оператором, закрывается при завершении; принятого внешнего или внутреннего входящего — через 60 секунд; непринятого внешнего или внутреннего входящего — только вручную. Для исходящего вызова доступны обычный звонок и отдельный звонок на громкой связи через FreePBX intercom. Клик по алерту открывает справочник с фильтром по ФИО участника; если имя не распознано, используется номер. Перед click-to-call всегда требуется явное подтверждение. Пароль не сохраняется; сессия автоматически продлевается и действует до 180 дней бездействия.
