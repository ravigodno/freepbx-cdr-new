# PBXPuls Desktop Alerts

## Установка для проверки

1. Откройте `chrome://extensions` или `edge://extensions`.
2. Включите режим разработчика.
3. Нажмите «Загрузить распакованное расширение» и выберите каталог `browser-extension`.
4. Откройте расширение, укажите адрес PBXPuls и войдите.
5. Нажмите «Проверить окно звонка» и убедитесь, что Chrome открыл отдельное окно.

Расширение показывает заявки и активные звонки в отдельном окне, а также перехватывает ссылки `tel:`. Клик по уведомлению о звонке или кнопке «Открыть в PBXPuls» открывает справочник с фильтром по ФИО участника; если имя не распознано, используется номер. Перед click-to-call всегда требуется явное подтверждение. Пароль не сохраняется; токен текущей сессии хранится локально в профиле браузера и действует 24 часа.
